# Mermaid Melody Pichi Pichi Pitch: Pichi Pichitto Live Start! English translation

Unofficial English fan translation of **Mermaid Melody Pichi Pichi Pitch: Pichi Pichitto Live Start!** (Game Boy
Advance, Konami, 2004): the source text and tools that build the patch.

**Just want to play?** Download the patch from [Releases](../../releases) and follow its README. This repository holds
no game data you can play; you need your own dump of the Japanese game.

**Found a bug?** [Report it](../../issues/new/choose): untranslated text, typos, overflow, crashes. Attaching a savestate
helps most.

## Translation status

| Part | Status |
|---|---|
| Story mode (39 episodes), character talk, Hippo's room | Translated |
| Menus, options, save prompts, results, card game and minigames | Translated |
| Graphics with text (menus, buttons, banners, mode cards, minigame logos, episode titles) | Redrawn in English |
| Title logo and copyright line | Left in Japanese (no official English logo) |
| Name entry | Latin letter keyboard (upper / lower case) |
| Song titles, song lyrics, credits roll | Translated (lyrics in romaji, as sung) |

Known issues: none known; see [Issues](../../issues).

## What's here

| Path | What it is |
|---|---|
| `script/` | Every text block: original Japanese and English. Translation fixes go here. |
| `glossary.md` | Binding names, terms and style rules. |
| `tools/` | Python build chain: extract, insert, lint, graphics, release. |
| `gfx/` | Redrawn graphics (generated by `tools/gfx_*.py`) and their tables. |
| `tests/` | pytest suite (ROM-dependent tests skip when the ROM is absent). |
| `docs/re/` | Reverse-engineering notes. |
| `docs/decisions.md`, `docs/status.md` | Rulings with their reasons; current progress and open bugs. |
| `docs/fonts.md` | Fonts used and their licences. |
| `AGENTS.md` | Instructions for coding agents (`CLAUDE.md` points to it). |
| `.codex/agents/`, `.opencode/agents/` | Subagent types (translator, reviewer, visual QA, playtester, graphics) for Codex and opencode; Claude Code gets them from the plugin. |

## Build your own patched ROM

Needs Python 3.12+ (with Pillow) and your own dump of the Japanese game.

```sh
git clone https://github.com/minhnhattonthat/mermaid-melody-pichi-pichi-pitch-pichi-pichitto-live-start-en
cd mermaid-melody-pichi-pichi-pitch-pichi-pichitto-live-start-en
# copy your dump to: rom/Mermaid Melody - Pichi Pichi Pitch - Pichi Pichitto Live Start! (Japan).gba
#   (No-Intro, 33554432 bytes, CRC32 7A4FDEC3, MD5 e5445bbb91fa514a63fd54bf1ce39cf8,
#    SHA-1 d6bd3140b83fb9b1c2d84b6faf21c7286e29d129; the build refuses any other dump, see rom.sha1)
python -X utf8 build.py                                # -> build/mermaid_en.gba
python -X utf8 tools/check.py                          # tests + text lint
```
