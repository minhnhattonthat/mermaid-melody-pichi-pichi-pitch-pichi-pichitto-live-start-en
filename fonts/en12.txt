# English VWF font for the 12x12 dialogue font (docs/re/text.md §Font, tools/enfont.py).
# Drawn for this project (MIT, same as the repo).
# Each glyph: "== C" (C = the character, or "space") then 10 core rows: row 0 accents, rows 1-7 caps/ascenders,
# rows 3-7 x-height, rows 8-9 descenders. '#' = black core; enfont.py adds the dark-grey bold pixel to the right.
# Core width <= 7, so the glyph with its bold column fits 9 px (4 shifts of a 12 px cell, see tools/vwf.py).
