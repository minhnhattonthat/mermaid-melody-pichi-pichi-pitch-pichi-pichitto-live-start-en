Mermaid Melody Pichi Pichi Pitch: Pichi Pichitto Live Start! - English translation v{version}
==========================================================================================

Unofficial fan translation of Mermaid Melody Pichi Pichi Pitch: Pichi Pichitto Live Start! (Game Boy Advance,
Konami, 2004).
Project page: https://github.com/minhnhattonthat/mermaid-melody-pichi-pichi-pitch-pichi-pichitto-live-start-en

HOW TO PATCH
1. Get your own dump of the Japanese game (no ROMs are provided, and patched ROMs must not be shared):
     {rom_name}
     size   {rom_size} bytes
     CRC32  {rom_crc}
     MD5    {rom_md5}
     SHA-1  {rom_sha1}
2. Apply {patch_name} with any BPS patcher (Floating IPS, beat, or https://www.marcrobledo.com/RomPatcher.js/).
3. The patched ROM: {out_size} bytes, CRC32 {out_crc}, SHA-1 {out_sha1}.

PLAYING
- Tested in MesenCE 2.2.1 (GBA core). Any accurate GBA emulator or a flash cart should work.
- Start from a cold boot (a fresh power-on), not from a savestate made with the Japanese ROM. The game saves to
  SRAM; set your emulator or flash cart to SRAM saves if it doesn't detect it.

TRANSLATION STATUS
- Story mode (39 episodes), character talk, menus, options, results, card game, minigames: translated.
- Graphics with text (menus, buttons, banners, mode cards, minigame logos, episode titles): redrawn in English.
- Song titles and credits: translated; song lyrics in romaji, as sung.
- Name entry: Latin letter keyboard.
- Left in Japanese: the title logo and its copyright line (there is no official English logo).
